**Lean registry: toolchain proxy + Lake build cache (#1029)** — NORA can now serve Lean/Lake builds the same way it serves Cargo and Conan: an elan-compatible toolchain proxy caches `leanprover/lean4` release archives on first fetch (`/lean/toolchains/{version}/{filename}`), and a hosted, content-addressed Lake build-cache endpoint (`/lean/cache/{hash}`) answers `LAKE_CACHE_ARTIFACT_ENDPOINT` `GET`/`PUT` so a team can share prebuilt `.olean`/`.ilean` artifacts instead of rebuilding `mathlib` on every machine. Both sides log to the activity feed and `audit.jsonl` like every other proxy format, and are off by default (`NORA_LEAN_ENABLED`).
